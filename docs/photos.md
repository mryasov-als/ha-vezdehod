# Камера и фото при нажатии

[← К началу](../README.md)

Если «Вездеход» возвращает камеру для выбранного шлагбаума, интеграция создаёт
сущность **«Камера»**. Она получает JPEG по мере запросов HA. Отображение
периодически обновляется, но это не исходный непрерывный видеопоток и не запись
видео. Обновление камеры само по себе не открывает шлагбаум.

## Сохранять фото при открытии

Откройте **Настройки → Устройства и службы → Вездеход** и настройки интеграции.
Включите флажок **«Сохранять фото при открытии»** для записи снимков.
По умолчанию флажок выключен.

Команда открытия отправляется сразу. Запрос фото выполняется в фоне через
**3 секунды после нажатия**, независимо от результата команды. Ошибка фото
не меняет результат открытия. Это снимок при попытке открытия, а не
подтверждение фактического положения шлагбаума.

До первого сохранённого кадра сущность **«Последнее фото открытия»** может
показывать **«Недоступно»** — изображение ещё не создано.

## Где смотреть и хранить

- Последний снимок — сущность **«Последнее фото открытия»** на странице устройства.
- Весь архив доступен через файлы конфигурации HA. На HAOS снимки находятся
  в `/config/vezdehod/snapshots/<хеш аккаунта>/<ID шлагбаума>/`.

При загрузке новой версии интеграция переносит старые кадры из каталога
локальных медиа в каталог конфигурации. Каждый файл удаляется из старой папки
после успешной записи в новую.

Кадры хранятся до ручного удаления. Флажок управляет записью новых снимков.

Имя файла содержит время **нажатия** в часовом поясе HA, микросекунды и
смещение относительно UTC: `2026-11-05_13-40-00_123456+0300.jpg`.
Часть `_123456` различает нажатия в одну секунду. Это не точное время
экспозиции камеры; сам JPEG запрашивается позже.

## Автоматизации и свои панели

У сущности последнего фото есть атрибуты `file_path`, `captured_at`, `saved_at`
и `barrier_id`. `captured_at` содержит время нажатия в UTC, а `saved_at` —
время сохранения. При сохранении создаётся событие
`vezdehod_snapshot_saved` с данными снимка, `entity_id` кнопки и исходным Context.

Эти данные доступны стандартным средствам HA для автоматизаций и своих
виджетов. Событие может относиться и к более раннему нажатию, поэтому
проверяйте `is_latest`, если показываете только последний кадр.

Отдельные сообщения о сохранении снимка в **«Активность»** не добавляются.
Штатная запись нажатия кнопки остаётся. Миниатюра фотографии в стандартном
диалоге сведений об активности не встраивается.
