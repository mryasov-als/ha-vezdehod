# Вход и получение ключа

[← К началу](../README.md)

Интеграции нужны **номер телефона** аккаунта и **mobile_key** — действующий
ключ сессии. Номер вводится только цифрами, с кодом страны, без `+`, пробелов
и скобок. Например, `79990001122` — это вымышленный номер для пояснения.

## Важно про SMS и разлогин

**Новый вход по SMS на другом устройстве разлогинивает предыдущий вход
в «Вездеход». Это проверено при входе на втором телефоне. Вход по SMS из HA
тоже может завершить сессию приложения на телефоне, а последующий новый вход
на телефоне — сделать ключ в HA недействительным.**

**Если хотите пользоваться текущей сессией на Android одновременно с HA,
импортируйте её существующий ключ, не создавая новый вход по SMS.**

Уже выданный ключ может перестать действовать позднее. Интеграция не запрашивает
новые SMS автоматически; восстановление доступа выполняется вами явно.

## Android: перенести текущий ключ через Windows

Потребуются Windows 10/11 **64 бит**, Android-телефон с уже работающим входом
в официальном «Вездеходе» и USB-кабель с передачей данных.

1. [Скачайте Вездеход Key Helper 0.1.2 (EXE)](https://github.com/mryasov-als/ha-vezdehod/releases/download/v0.4.4/vezdehod-key-helper.exe).
2. На телефоне включите режим разработчика: обычно **Настройки → О телефоне**,
   несколько нажатий на **«Номер сборки»**. На Xiaomi это может быть версия
   MIUI/HyperOS. Затем в разделе **«Для разработчиков»** включите
   **«Отладка по USB»**. Путь зависит от производителя; подсказка есть в EXE.
3. Подключите телефон к компьютеру и разблокируйте его.
4. Запустите EXE и нажмите **«Старт»**. На телефоне разрешите отладку с этого ПК.
5. Когда программа попросит, **откройте список шлагбаумов в «Вездеходе»**.
   Приложение должно выполнить свежий запрос. Если список уже открыт,
   выйдите из него и откройте снова; при необходимости потяните список вниз.
6. После обнаружения программа остановит поиск и покажет номер и ключ.
   Нажмите отдельные кнопки **«Копировать»** рядом с каждым полем.
7. В форме добавления интеграции HA выберите **«Ввести готовый ключ»**,
   вставьте номер и ключ, подтвердите и выберите шлагбаумы.

Не нужно устанавливать Python, Android Studio, ADB или дополнительный APK.
ADB включён в EXE. После получения ключа USB-отладку можно выключить.

### Что делает программа

Программа читает свежие записи журнала только процесса «Вездехода» через
разрешённую USB-отладку. В них ищутся запросы `get_facility` / `check_auth`
с номером и ключом. После находки, нажатия **«Стоп»** или тайм-аута чтение
прекращается. Сетевой трафик программа не расшифровывает.

Номер, ключ и журнал не сохраняются в файлы и не отправляются программой
в интернет. Копирование в обычный буфер обмена Windows — только по кнопке.
Ключ не проверяется программой по сети: проверку выполняет интеграция HA
при импорте. SMS и команды открытия помощник не отправляет.

Работа подтверждена пользователем на Android. Если другая версия «Вездехода»
не записывает запросы в журнал, этот способ не найдёт ключ. Сообщение
**«Данные не найдены»** не означает, что ключ недействителен.

Если телефон не определяется, проверьте кабель, запрос разрешения и режим
USB; иногда требуется драйвер производителя. Подключайте один USB-телефон
за раз. На время поиска телефон должен оставаться подключённым.

[Исходники и сборка EXE](../tools/key-helper/README.md).
[Официальная справка Android по USB-отладке и ADB](https://developer.android.com/tools/adb).

## Вход по SMS непосредственно в HA

Этот способ не требует Windows, EXE, Android или USB-подключения.

1. В добавлении интеграции выберите **«Войти по SMS»**.
2. Введите номер только цифрами и подтвердите. HA отправит один запрос SMS.
3. Введите полученный код. После проверки HA сохранит ключ и предложит
   выбрать шлагбаумы.

Повторная отправка SMS доступна по вашему действию после паузы 60 секунд.
Если код уже подтверждён, но список не загрузился из-за ошибки сети,
следуйте пояснению формы: повторите подтверждение без кода.

**Этот способ создаёт новый вход. Учитывайте предупреждение о разлогине
другого устройства в начале инструкции.**

## iPhone

**Проверенного способа извлечь действующий ключ из iOS-версии «Вездехода»
пока нет. Windows-помощник работает только с Android.**

Можно войти по SMS в самом HA; повторно получать ключ вручную при этом
не требуется. Вход из HA может завершить текущую сессию «Вездехода» на iPhone.

Возможные направления исследования — журнал подключённого iPhone через
«Консоль» на Mac или HTTPS-прокси с доверенным сертификатом. Неизвестно,
записывает ли iOS-приложение ключ в журнал и допускает ли такой прокси.
Защита сертификата в приложении может блокировать расшифровку. Это
**непроверенные варианты, а не готовая инструкция получения ключа**.
[Журналы iPhone на Mac — Apple](https://support.apple.com/guide/console/log-messages-cnsl1012/mac),
[HTTPS на iOS — Charles](https://www.charlesproxy.com/documentation/using-charles/ssl-certificates/),
[ограничение при защите сертификата — Charles](https://www.charlesproxy.com/documentation/faqs/).

## Если доступ пропал

У аккаунта есть сенсор **«Статус ключа»**: `1` — последняя проверка успешна,
`0` — сеть или ответ не позволили проверить доступ, `-1` — сервис отклонил ключ.
При явном отказе HA предложит восстановить доступ. Кнопка открытия остаётся
доступной: кратковременная ошибка проверки не запрещает новую команду.

Для ручной замены откройте **Настройки → Устройства и службы → Вездеход**,
в меню **⋮** учётной записи выберите **«Перенастроить»** и способ входа.
Не удаляйте интеграцию только ради обновления ключа — используйте тот же номер.
