# Вездеход (Vezdehod) для Home Assistant

Неофициальная интеграция шлагбаумов сервиса **«Вездеход / Комендант 24»**.
Позволяет открывать доступные вашему аккаунту шлагбаумы из Home Assistant,
Android Auto и голосовой командой через Google Home.

**Пока интеграция не включена в основной каталог HACS. Для установки нужно
один раз добавить этот репозиторий в HACS вручную — инструкция ниже.
После включения в каталог эта пометка будет убрана.**

**Важно: новый вход по SMS на другом устройстве разлогинивает предыдущую
сессию «Вездехода». Чтобы сохранить действующий вход на Android, импортируйте
существующий ключ с помощью Windows-программы.**

## Что умеет

- Создаёт кнопку **«Открыть»** для каждого выбранного шлагбаума.
- Проверяет доступ без открытия шлагбаума и показывает числовой статус ключа.
- Добавляет камеру из периодически получаемых JPEG, если камера доступна
  аккаунту. Это последовательность снимков, а не исходный видеопоток.
- По желанию сохраняет фото через **3 секунды после нажатия**: последнее
  фото доступно отдельной сущностью, архив — через **«Медиа»**.
- Работает со стандартными кнопками, автоматизациями и панелями HA.
- Поддерживает вход по SMS прямо в HA и импорт существующей пары номер/ключ.

Шлагбаум представлен кнопкой: интеграция отправляет команду, но не получает
достоверного состояния «открыт / закрыт». Для работы нужен интернет у HA
и доступ к сервису «Вездеход».

## Установка через HACS

Требуется **Home Assistant 2026.10.4 или новее** и установленный HACS.

1. В HA откройте **HACS → ⋮ → Пользовательские репозитории**.
2. Вставьте адрес `https://github.com/mryasov-als/ha-vezdehod`.
3. Выберите тип **«Интеграция»** и добавьте репозиторий.
4. Найдите **«Вездеход (Vezdehod)»**, установите интеграцию и перезапустите HA.
5. Откройте **Настройки → Устройства и службы → Добавить интеграцию**.
   Найдите **«Вездеход»**.
6. Выберите способ входа, затем отметьте нужные шлагбаумы.

[Официальная инструкция HACS для пользовательских репозиториев](https://www.hacs.xyz/docs/faq/custom_repositories/).

Для установки без HACS скачайте `vezdehod-0.4.3.zip` из
[релиза](https://github.com/mryasov-als/ha-vezdehod/releases/tag/v0.4.3)
и перенесите из архива папку `custom_components/vezdehod` в каталог
`custom_components` вашей конфигурации HA. Затем перезапустите HA и выполните
шаги 5–6. Если интеграция уже установлена вручную, сохраните тот же домен
`vezdehod`: после установки через HACS существующая учётная запись сохраняется.

## Получение ключа и вход

**Новый вход по SMS может оставить без действующей сессии приложение на
телефоне или ранее настроенный HA. Импорт существующего ключа не создаёт
новую SMS-сессию.**

- **Android + Windows:** [скачать EXE получения ключа](https://github.com/mryasov-als/ha-vezdehod/releases/download/v0.4.3/vezdehod-key-helper.exe).
  Программа запускается на Windows и читает данные с вашего Android-телефона
  по USB. Это не APK; отдельная установка ADB не требуется.
- **Любой телефон:** можно получить SMS и войти прямо в форме интеграции HA.
- **iPhone:** проверенного способа извлечения ключа текущего входа пока нет.
  Вход по SMS в HA доступен без Android.

[Подробная инструкция: Android, SMS, iPhone и замена ключа](docs/credentials.md).

## Сущности и фотографии

| Сущность | Для чего |
| --- | --- |
| **Открыть** (`button`) | Одна команда открытия выбранного шлагбаума |
| **Статус ключа** (`sensor`) | `1` — ключ принят, `0` — ошибка последней проверки, `-1` — ключ отклонён |
| **Камера** (`camera`) | Обновляемые JPEG с камеры шлагбаума, если она доступна |
| **Последнее фото открытия** (`image`) | Снимок, связанный с последним нажатием, если сохранение включено |

Статус ключа относится к последнему запросу списка шлагбаумов, обычно раз
в 30 минут. Доступны атрибуты `last_check`, `last_successful_check`, `last_error`.
Ошибка такой проверки **не блокирует кнопку**; явное нажатие снова отправляет
команду сервису. Успешность самой команды проверяется отдельно.
[Подробно: где найти статус ключа и как использовать его в автоматизациях](docs/key-status.md).

Флажок **«Сохранять фото при открытии»** находится в настройках интеграции.
Сохранение включено по умолчанию; его можно отключить.
[Как работает архив, задержка и доступ к фото](docs/photos.md).

## Обновления и поддержка

Обновления интеграции устанавливаются через HACS. Windows-помощник обновляется
отдельной загрузкой EXE, если он вам нужен. [Изменения версий](CHANGELOG.md).

Об ошибках сообщайте в [Issues](https://github.com/mryasov-als/ha-vezdehod/issues).
Укажите версию HA, версию интеграции и описание ошибки. **Не публикуйте номер,
ключ, SMS-коды и полные адреса запросов с данными доступа.**
